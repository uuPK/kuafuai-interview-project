离线验证包括：非流式请求、`auto` 工具选择、模型/思考开关/effort/输出上限参数，连续工具与普通文本轮次的思考字段回传，完整响应/扩展字段/token 用量保存；401/403 鉴权、402 余额、400/422 协议、404/重定向配置、429/5xx 临时故障分类；超时、响应读取中断、无效或非有限 JSON、响应大小限制、凭据隔离和脱敏摘要。适配器每次调用只发送一次 HTTP 请求，有限重试和计数由 harness 处理。

按 [DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、[工具调用](https://api-docs.deepseek.com/guides/tool_calls/)、[思考模式](https://api-docs.deepseek.com/guides/thinking_mode/) 与 [错误码](https://api-docs.deepseek.com/quick_start/error_codes/) 实现。携带工具时保留所有历史思考字段，包括未调用工具的轮次；思考模式读取 reasoning_effort，普通模式读取 temperature。

真实模型目录查询 HTTP 200，账号返回 `deepseek-flash`、`deepseek-v4-pro`。本地选用 `deepseek-flash`，生产配置保持普通模式；下面的思考验收通过单次测试配置启用 `low` effort。每次请求输出上限 2048 tokens，每模式最多 8 次请求，真实测试关闭自动重试以限制用量。

| 真实协议验收 | 结果 | 模型请求 | 逻辑搜索/抓取/工具调用 | 输入/输出/总 token | 耗时 |
| --- | --- | --- | --- | --- | --- |
| 普通模式 | completed；完整配对 | 5 | 2 / 1 / 4 | 4760 / 230 / 4990 | 5.67 秒 |
| 思考模式，low effort | completed；完整配对 | 5 | 2 / 1 / 4 | 4958 / 252 / 5210 | 5.00 秒 |

两种模式均先产生一次无工具的准备回复，再执行零结果 → 英文补查 → 固定原文抓取 → 中文测试稿提交。思考模式五轮响应均包含 reasoning_content，后续持久请求中依次带回 1、2、3、4 个历史思考字段。完整响应和请求保存在本地 SQLite，统计与事件在 Git 忽略的 `data/acceptance/deepseek-live-2026-10-12.json`；代码仓库只保存本节统计，不上传密钥、思考内容或运行数据库。

真实接口为 [博查开放平台](https://open.bochaai.com/) 公布的 `POST https://api.bochaai.com/v1/web-search`。本次共 6 次小请求，均 HTTP 200 / code 200，每次关闭自动重试；其中 4 次通过工具执行器，计 4 次逻辑搜索与 4 次工具调用，其余 2 次为供应商契约/参数探测。没有调用 DeepSeek、抓取正文或 SMTP。

| 真实请求 | 返回与校验 | 耗时 |
| --- | --- | --- |
| 中文契约探测，count=5 | 5 条；确认 code/log_id/msg/data 外层及原始日期字段 | 1.05 秒 |
| 中文工具调用，count=3 | 3 条候选；保存 ID、原始响应与搜索事件，按当前用户读回 | 0.54 秒 |
| 英文 site 条件探测，count=3 | 返回 3 条越域结果；本地校验过滤全部，反馈 domain=3 | 0.24 秒 |
| 随机查询，count=1 | 有效零结果，保存成功的空发现快照 | 0.17 秒 |
| 英文查询及 include=huggingface.co，count=3 | 有效零结果；接口接受 include，不能据此认定该域没有相关新闻 | 1.25 秒 |
| 中文工具调用及 include=qq.com，count=3 | 3 条；全部为 news.qq.com 链接，保存候选与结果 | 0.58 秒 |

已实测映射 include，继续发送 site 条件及核对返回 URL；仅凭 site 文本不能保证域名范围。英文查询不保证材料语言，实测 language 为 null。样本中 datePublished 的 `+08:00` 与 dateLastCrawled 的 `Z` 写法不同；保持原始值，尚未验收其实际时间语义或正文发布时间。oneDay 也不代表已经通过固定新闻窗口检查。

`tests/fixtures/bocha-success.json` 来自真实响应，替换 log_id，保留前两条记录及可空字段，snippet/summary 最多保留 150 字符，供可重复离线契约测试。完整脱敏响应与统计保留于 Git 忽略的 `data/acceptance/bocha-probe-2026-10-12.json`、`bocha-include-probe-2026-10-12.json`、`bocha-live-2026-10-12.json`，工具数据库位于 `data/acceptance/bocha-live-2026-10-12/news.sqlite3`。
